# VS Code Extension Samples (reference)

Trimmed copy of https://github.com/microsoft/vscode-extension-samples
(license: MIT). Only source code kept: `*.ts` / `*.tsx` plus minimal
`package.json` / `tsconfig.json` / `eslint.config.mjs` per sample.

Removed: images/gifs, demos, lockfiles, `.vscode/`, repo infra
(`.github`, `.scripts`, `.base-sample`), notebooks, wasm cargo artifacts.

Each directory is a self-contained VS Code extension sample. See SKILL.md
section "25. Reference Samples" in the skill root for the topic-to-sample mapping.
